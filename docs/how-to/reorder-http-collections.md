# Reorder HTTP collections

Related: [HTTP collections](../http-collections.md).

1. Open **HTTP**.
2. Drag the grip at the left of a collection row up or down. Drop it on the row that should take its place.
3. Open that collection and do the same on a request row.

The new order is stored as `sort_order` and survives refresh. Requests stay inside their collection.
